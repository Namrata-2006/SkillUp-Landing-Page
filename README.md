# SkillUp – Responsive Landing Page

## Project Overview
SkillUp is a fictional online learning platform landing page designed using Figma for a UI/UX Design assignment.

## Target Audience
College students, beginners, and job seekers who want to develop new skills.

## Design Features
- Header with logo, navigation, and call-to-action button
- Hero section with heading, description, and illustration
- Three feature cards: Expert Courses, Learn Anywhere, and Certificates
- Footer section
- Desktop and mobile layouts

## Tools Used
- Figma
- Auto Layout
- Reusable components
- Typography and color styles

## Design Choices
Purple and lavender colors create a modern, friendly learning experience. Clear headings, consistent spacing, and simple icons make the design easy to understand.
